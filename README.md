# 🧠 AI Image Caption Generator

This project generates captions for images using Deep Learning.

## 🚀 Features

* Upload any image
* Automatically generates caption
* Uses CNN + LSTM model
* Clean and modern UI

## 🛠️ Tech Stack

* Python
* Flask
* TensorFlow / Keras
* ResNet50 (Feature Extraction)

## ▶️ How to Run

```bash
pip install -r requirements.txt
python app.py
```

Open browser:

```
http://127.0.0.1:5000
```

## 📸 Example Output

* "A dog playing with water hose"
* "A man sitting on a bench"
